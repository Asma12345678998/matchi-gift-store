# ماتشي | MATCHI

متجر هدايا فاخر بتجربة سينمائية — a luxury cinematic gift experience.

## المميزات
- مقدمة سينمائية بعدّ تنازلي وأشرطة Letterbox
- بطل الصفحة مع جزيئات ذهبية متحركة، أشعة ضوء، وإضاءة تتبع المؤشر
- حبيبات فيلم (Film grain) وتعتيم أطراف (Vignette)
- مجموعات منتجات مع فلترة وتأثير ميلان ثلاثي الأبعاد
- صندوق التوقيع ثلاثي الأبعاد يُفتح بالضغط
- سلة هدايا محفوظة في المتصفح، عدّادات متحركة، آراء العملاء، وستارة مسرح تُفتح عند المشهد الأخير
- يدعم العربية (RTL) والجوال

## التشغيل
موقع ثابت بلا أي اعتماديات — افتح `index.html` مباشرة، أو:

```bash
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
